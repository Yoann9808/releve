# Spécifications

Une spec par feature validée, nommée `<id-notion-court>-<slug>.md`. Chaque spec contient : problème adressé (avec les pains sources), comportement attendu, cas limites, critères d'acceptation, métrique de succès.

Les specs sont écrites par l'agent Produit à partir du backlog Notion une fois la feature validée par Yoann, puis relues avant tout développement.
